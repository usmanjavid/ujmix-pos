# UJMix POS quick start

Install on Windows 10/11 x64. Setup offers with or without the local AI model. Create an owner account, select the store currency, and enter at least one phone number (two more are optional). Currency locks after financial records exist.

1. Import products from CSV/Excel; review the preview and correct errors before saving. Add opening stock and prices.
2. Open Settings → Security, create a recovery code, and keep it somewhere secure outside this PC. Set a session timeout and create staff accounts.
3. Open Settings → Backup. Set a strong portable backup password and choose daily, weekly or monthly. Keep a separate manual backup before upgrades. Scheduled backups replace the previous scheduled copy.
4. For cloud storage, sign in to your own OneDrive (default), Proton Drive, Google Drive or Dropbox desktop app, then choose its synced folder. Keep the backup folder available offline. UJMix POS confirms a local copy; check the provider app to confirm upload. No OAuth app registration is needed.
5. Test the printer under Settings. Preview your receipt size, select the printer in the Windows print dialog, then confirm the result. Test your barcode scanner as a keyboard device.
6. Send the owner your shop name, PC activation code and chosen term. Import the returned customer license under Settings → Licensing. Never accept an issuer key or owner generator as a customer download.

At checkout, scan a barcode or type SKU/name and press Enter. Up/down adjust the selected line. Unfinished carts and manual invoices are saved in the encrypted database; recovery does not complete a sale automatically. Review recovered quantities and current prices. Invoice history supports search, reprint and authorized POS refunds. Cashier discounts/refunds require an owner or manager's credentials and reason. Manual invoices do not change inventory, POS sales, cashbook or customer credit.

Instant insight buttons use local database queries without loading AI. Optional local AI interprets questions on this PC; financial results still use approved database queries. Leave Eco mode on older PCs; Automatic can benchmark CPU versus available Vulkan acceleration. An Intel iGPU is not guaranteed to accelerate inference. AI is loaded on demand and normally unloads after ten idle minutes; settings can change this.

Use the readiness checklist and run separate demo data before using live records. Demo reset affects only the demo profile. True fullscreen exits with Esc. Diagnostics can be previewed and saved locally; sending them to support is your choice.
